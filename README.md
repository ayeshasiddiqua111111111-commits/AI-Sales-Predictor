# 📈 AI Sales Predictor (Next.js Web App)

An interactive AI-powered marketing forecast dashboard built with **Next.js & React**, predicting sales performance from multi-channel advertising budgets using 2nd-degree Polynomial Regression with cross-channel synergy modeling.

## 🚀 Live Demo & Deployment
Built for seamless deployment on **[Vercel](https://vercel.com)**.

## 🛠️ Features
- **Next.js Real-Time Forecast Engine**: Non-linear polynomial machine learning inference.
- **Cross-Channel Synergy Simulation**: Measures the combined interaction lift (TV × Radio).
- **Interactive Budget Sliders**: Test any combination of advertising channel allocations.
- **Scenario Presets**: Balanced Mix, Radio Synergy Blitz, Prime-Time TV Dominant, Lean Budget.
- **Interactive Scatter Plot**: Current allocation plotted against 200 historical campaign records.
- **Dataset Explorer**: Full searchable, sortable, and paginated campaign dataset.
- **Model Diagnostics**: Mathematical equation, regression weights, and accuracy metrics (R² = 95.33%, MAE = 0.903).
